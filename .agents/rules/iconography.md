# Iconography Guidelines

- **Zero Unicode Emojis**: Never use emojis in component JSX, labels, tooltips, buttons, banners, or data strings.
- **Animated SVGs & Icons**: Always use styled SVG icons from `AspirantIcons.jsx` or inline `<svg>` with CSS animations.
- **Mascots**: Render the Cat Mascot using custom SVG vector graphics or CSS-animated vector shapes, never emoji characters.
